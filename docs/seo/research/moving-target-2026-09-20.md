## Research boundary

This run covered one drill only. No English page was translated into a localized page. Localized metadata, visible drill titles, keyword clusters, and guide headings were rewritten from native-market SERP evidence. The existing full guide, scientific citations, benchmark rows, training steps, structured data, and ten localized FAQ entries were retained.

Google Trends was checked as a required source, but this environment exposed only the Trends landing/regional pages and not query-level time-series values. No Trends number is presented as measured demand. Search Console was not available in this run. Bing figures below are Bing estimates, never Google volume.

## Brazil (`pt-BR`)

Native evidence: [CDhistory](https://cdhistory.org/pt/teste-de-rastreamento/) uses `Teste de Rastreamento` and `Busca Suave`; [Interacoustics VisualEyes manual](https://www.interacoustics.com/images/files/manuals/ptbr/D-0134106-C_2025_04_Instructions_for_Use_VisualEyes_3.2_BRPT_copy_1.pdf) uses `teste de perseguição lenta` for following a moving target. Generic `rastreamento` is dominated by Correios/logistics intent in Brazil, so it is paired with visual and target modifiers.

Cluster: primary `rastreamento visual`, `perseguição visual`; secondary `teste de rastreamento visual`, `perseguição ocular`, `alvo em movimento`, `interceptação de alvo`, `coordenação olho-mão`, `visão dinâmica`, `treino de mira em alvo móvel`, `velocidade de rastreamento`, `trajetória de alvo`.

Bing (`br/pt-BR`): `rastreamento visual` related results were dominated by Correios terms (for example `correios rastreamento 71306`); `perseguição visual` was dominated by software/visual-search terms. These ambiguous suggestions were excluded from title copy.
