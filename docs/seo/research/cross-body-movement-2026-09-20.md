## Search intent and page decision

This drill is a browser-based hand-eye/eye-hand coordination test built around diagonal cursor movement across the body midline. The page therefore targets the native market terms for coordination tests and games first, with bilateral coordination, visuomotor control, fine-motor precision, and mouse/aim training as supporting intent. Titles and visible subtitles are deliberately short so the drill UI remains readable.

No English page was machine-translated. Each localized metadata set and visible drill label was authored around that market's observed search language and terminology.
