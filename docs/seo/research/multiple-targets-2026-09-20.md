# Multiple Targets — native SEO/AEO/GEO research

Research date: 2026-09-20  
Route: `/drills/visual/tracking-accuracy/multiple-targets`  
Localized routes: `/ja/`, `/ko/`, `/de/`, `/pt/`, `/es/`, `/fr/`

## Research boundary

This is native query research for a human visual multiple-object-tracking drill. The page targets visual attention, simultaneous target tracking, divided attention, peripheral awareness, and visuospatial working memory. It does not target computer-vision MOT systems, parcel tracking, flight tracking, or medical diagnosis.

The localized pages retain their existing full scientific guides and FAQs. The work below changes search-facing wording around the locally observed intent; it does not translate the English page into another language.

Exact Google monthly volume, Google Trends query-level values, GSC query data, and backlink authority are not available in this workspace. Bing related-query output is therefore recorded as Bing evidence only, never as Google volume or proof of low competition. Google web results and localized publisher terminology were used to select native phrasing. No ranking or #1 outcome is guaranteed.

## AEO/GEO implementation decisions

- Each localized title front-loads the native visual-tracking entity and stays compact enough for a SERP title.
- Descriptions answer what the drill does, name the attention/peripheral-vision benefit, and state that it is not a diagnostic test where appropriate.
- Existing localized guide depth, benchmark table, protocol steps, scientific sources, and ten distinct FAQs are preserved.
- The interactive drill remains above the guide, with the localized H1/subtitle and localized schema names aligned to the same intent.
- Canonicals, reciprocal alternate-language metadata, localized internal links, `WebApplication`, `SoftwareApplication`, `HowTo`, and `FAQPage` JSON-LD remain on each page.
- No IndexNow/Bing submission was performed. The sitemap last-modified override will be updated only for this drill after the copy change.
