# Demand / competition research brief (shared by all market agents)

Goal: for ONE market, find keywords with high measured demand and low competition that skilldrills.online (free browser skill tests/drills: cps/click speed, aim trainer, reaction/reflex, typing + keyboard tester, memory, brain training, stroop, mental math, speed reading, concentration, mouse accuracy, eye/visual tests) can honestly serve, in the market's LOCAL language and search behaviour, and say how to rank for them with SEO + AEO (answer engines/snippets) + GEO (generative engines, local engines).

Tools (all tested, run from the repo root C:\Users\sangmesh\Desktop\global-drill-system-nextjs - Copy):
1. Discovery: `python scripts/keywords/autocomplete.py "<seed>" <cc> <lang> --expand` (Google Suggest; PROXY only, never volume). Also scripts/keywords/native_discovery.py, country_keywords.py exist.
2. Demand (measured, Bing Webmaster API exact monthly impressions): put `phrase<TAB>cc<TAB>lang` lines in a UTF-8 file and run `python scripts/keywords/bing_kw.py --file <file> [--trend]` (output JSON lines). It is rate-limited across ALL agents by a shared lock (about 3.5 s/call globally), so budget: at most 70 phrases per agent, --trend only on the ~20 best. Never call scripts/bing/bing.py keyword directly. status "nodata" = UNKNOWN, not zero. Diacritics matter (accented and unaccented are different keywords): test the accented form. Bing is only ~3-4% of search, so numbers are a relative index, not Google volume.
3. Competition + answer-engine signals: write `query<TAB>cc<TAB>lang` UTF-8 file, run `node scripts/keywords/serp_probe.mjs --file <file> <out.jsonl>` (Playwright, Bing SERP for that market; top-10 hosts/titles/snippets, answers count, copilot flag, ads). It waits 4-7 s per query. If `captcha:true` or errors appear, stop and wait 5 minutes, then continue at lower rate. Run at most ~40 probes. NEVER pass CJK/accented text on the command line (the Windows shell mangles it): always use files. No logins, no accounts; free public sources only. Google Trends is blocked (429) - do not try it. Bing trend (--trend) is the trend source.
4. Existing site coverage: lib/drillsRegistry.js (routes), docs/seo/PAGE_QUEUE.md, docs/seo/INTERNATIONAL_STRATEGY.md, and memory-derived prior numbers below.

Prior measured numbers (Bing exact/mo, 2026-09): US cps test 13,907; reaction time test 5,394 (now 12,679); aim trainer 4,834 (9,821 later); keyboard tester 13,729 (17,184 on 2026-10-08, trend flat); KR 반응속도 테스트 13,122, 한컴타자연습 176,386, 타자연습 95,223; JP タイピング練習 149,616, タイピング 100,001, 反射神経テスト 3,487; BR teste de digitação 14,810; FR reaction demand ~0 (English term 282); DE reaktionstest 750 and English beats native; Italy/Poland/Turkey no local-language win.

Method per market:
A. Seeds: 40+ native seeds across the tool categories above, plus local competitor/brand queries (what locals call these tools), question forms (how/what/why in the language), and gaming-game-specific variants. Expand with autocomplete. Think like a native searcher; do NOT translate English phrases mechanically; verify phrasings with autocomplete/SERP titles.
B. Shortlist <=70 candidates -> measure with bing_kw.py (accented forms!). Record exact, broad, status, trend.
C. For the ~25 best by exact volume plus ~10 mid-volume (30-1000) terms with unclear competition, run serp_probe. Classify each SERP:
   - hosts in top 10 grouped: BRAND (established dedicated product/incumbent, e.g. humanbenchmark, aimlabs, monkeytype, 10fastfingers, typingclub, speedtest.net, 한컴, e-typing, Wikipedia/YouTube/news portals), THIN-TOOL (single-purpose utility/tool-farm domains, e.g. key-test.com, cps-check, onlinemictest), FORUM/QA (reddit, quora, 知恵袋, Naver 지식iN, Zhihu...), BLOG/listicle.
   - competition: LOW if >=3 of top 5 are THIN-TOOL/FORUM/BLOG or titles do not match the exact query; MEDIUM mixed; HIGH if top 3 are BRAND with dedicated products.
   - AEO signals: answers count, copilot flag, snippet style, question forms that lead.
D. Opportunity = measured exact volume x competition multiplier (LOW 1.0, MED 0.5, HIGH 0.2) x feasibility (YES=existing/simple tool can satisfy intent honestly, PARTLY, NO). Rank by it.
E. Per top-15 opportunity: native keyword, exact vol, broad, trend, competition class with the top-5 hosts as evidence, search intent, which existing site route serves it (or "NEW tool needed" + what), recommended H1/title/description pattern in the native language (title<=60 chars incl. brand), 3-5 native question H2s + the 40-60 word direct-answer pattern (AEO), entities/terms to include, local-engine notes (Naver, Yahoo Japan which uses Google, Yandex, etc.), schema (FAQPage/HowTo/SoftwareApplication) notes (GEO). Also a KILL list: phrases the site currently targets with zero or unknown demand in this market (check titles in the market's app/<loc>/ pages) and what to do instead.
F. Be honest: label every number `measured (Bing exact)` or `proxy`. No fabricated volumes. If a market is thin, say so and recommend NOT building localized pages (the standard forbids pages without verified demand: docs/seo/NO_TRANSLATION_NATIVE_SEARCH_MANDATE.md).
