# Object Location international SEO/AEO/GEO research — 2026-09-20

Scope: the existing Object Location drill only (`/drills/memory/spatial-memory/object-location`) and its six locale routes. No other drill was researched or generated in this run.

## Evidence and limits

- Bing Webmaster `GetKeyword` was queried with the configured project key for each native primary phrase and one native synonym per market. Every checked phrase returned `0 exact / 0 broad`; this is Bing-data sparsity, not proof of zero Google demand.
- Native-language SERP research was used to identify terminology, task framing, and answer intent. SERP presence is not a monthly-volume metric.
- Google Trends was attempted with a country-scoped Explore URL, but the endpoint was inaccessible from this environment. No Trends score is claimed.
- Google Search Console and Google Keyword Planner are not connected, so no Google impressions, clicks, CTR, volume, or competition score is claimed.
- No IndexNow, Bing URL submission, sitemap submission, or other search-engine push was performed.

## SERP and answer-intent observations

- Germany: native pages use `Gedächtnisraster`, object positions, and Corsi/visuospatial-memory framing: [BB Gym Gedächtnisraster](https://bbgym.club/de/trainers/memory-grid/), [CogniFit Positionstest](https://www.cognifit.com/de/battery-of-tests/vismen-scavi-test/positions-test), [German spatial memory overview](https://de.wikipedia.org/wiki/R%C3%A4umliches_Ged%C3%A4chtnis).
- Spain: tools frame the task as an online `test de memoria espacial` and distinguish spatial span from verbal memory: [Soundary spatial memory test](https://soundary.life/es/test/spatial-span), [Gottrix visual-memory test](https://gottrix.app/es/test-de-memoria-visual), [ReflexBench spatial working-memory test](https://reflexbench.com/es/assessments/chimp-test/).
- France: authoritative/localized terminology centers on `mémoire spatiale`, `mémoire visuelle et spatiale`, and position recall: [French spatial-memory overview](https://fr.wikipedia.org/wiki/M%C3%A9moire_spatiale), [French working-memory overview](https://fr.wikipedia.org/wiki/M%C3%A9moire_de_travail), [Pearson visual-spatial assessment](https://www.pearsonclinical.fr/mwdownloads/download/link/id/688/).
- Japan: current Japanese results use `空間視覚`, relative object position, placement, and spatial-memory training: [Japanese spatial-visual app result](https://play.google.com/store/apps/details?hl=ja&id=com.tellmewow.senior.visuospatial), [位置推理・空間認識 game](https://asobi.kids/guide/where-is-it/), [Japanese position-memory research result](https://www.jstage.jst.go.jp/article/jje/58/Supplement/58_1E1-04/_pdf/-char/ja).
- Brazil/Portugal: localized tools use `teste de memória espacial`, `memória visuoespacial`, object locations, and grid recall: [Memo visual-spatial test](https://www.memo-app.com/pt/tools/visual-memory-test), [Soundary spatial span](https://soundary.life/pt/test/spatial-span), [BB Gym memory grid](https://bbgym.club/pt/trainers/memory-grid/), [Cognitive Train spatial-memory test](https://cognitivetrain.com/spatial-memory-test/).
- Korea: public indexed results were noisy for this niche query; the chosen cluster follows native Korean usage for spatial memory, object position, and visuospatial working memory rather than translating the English slug.

## 14-step audit summary

1. Candidate queries: the primary and supporting native clusters in the table above.
2. Intent: interactive spatial-memory/object-position training, not a medical diagnosis.
3. Ranking format: localized browser tools and cognitive-training pages lead; the drill remains interactive above the guide.
4. Localization: phrases were selected from native SERP wording and native query seeds, not word-for-word English translation.
5. Title/H1: each route front-loads the native primary phrase and keeps the brand suffix compact.
6. Authority: no backlink/domain-rating dataset is available; no easy-competition claim is made.
7. Feature gap: SkillDrills combines object-location recall, expanding grids, adaptive scoring, a scientific guide, benchmark rows, and no-login play.
8. PAA: observed questions concern what spatial memory measures, how object position is recalled, Corsi differences, and whether an online task is diagnostic; the existing localized FAQ set retains ten bespoke answers.
9. Autocomplete: no reliable locale-specific autocomplete volume was available in this environment.
10. Competitor matrix: competitors offer grid/position tasks; SkillDrills adds adaptive progression, transparent browser timing, benchmarks, and methodology.
11. Difficulty: unscored; Bing returned no measurable demand and authority data is unavailable.
12. Volume cross-check: Bing 0/0 for all checked phrases; Google Trends inaccessible; GSC unavailable.
13. Keyword cluster: one native primary plus object-position, spatial-memory, visuospatial-working-memory, and training modifiers per locale.
14. Ranking probability: not calculable responsibly without GSC, Google volume, and backlink data; no #1 guarantee is made.
