# Quick Dodge localized SEO/AEO/GEO research — 2026-09-20

## Scope

This is an individual research pass for `/drills/physical/reflex-training/quick-dodge` and its English, Japanese, Korean, German, Portuguese, Spanish, and French routes. The page is a browser cursor-evasion drill: users steer a cursor around incoming projectiles, survive longer, and receive score/combo feedback.

No English copy was translated into another locale. Each locale keeps its existing native guide and was retargeted with locally phrased search intent for mouse evasion, reflex testing, projectile dodging, and browser games.

## Live web evidence reviewed

- Japanese search intent: [弾幕STG たわし on Google Play](https://play.google.com/store/apps/details?hl=ja&id=jp.muis.tawashi) uses native `敵の弾を避けて` and `弾幕` language for projectile avoidance.

- German intent: [Mäuse-Rush](https://crazygames-poki.com/de/hypercasual/mice-rush) uses `Barrieren ausweichen` and `schnelle Reflexe` in a mouse-controlled game context.
- German test intent: [ZeroedTools Reaktionstest](https://www.dfaccount.com/de/reaction-test) confirms native `Reaktionstest` / `Reflex` terminology and explains browser, mouse, and display latency.
- English mechanics: [Avoid the Obstacles](https://oneyfy.com/games/avoid-obstacles/) and [Orbit Dodge](https://abracalc.com/game/orbit-dodge/) show browser intent around mouse movement, incoming obstacles, and survival time.
- French training intent: [ReflexBench French](https://reflexbench.com/fr/) uses `test de réaction en ligne` and `drills d'entraînement` language, including projectile-evasion drills.
- Portuguese native context: [CENSUPEG's Teste de Tempo de Reação com Régua](https://comunicacao.censupeg.com.br/reacao-de-regua) confirms natural Brazilian Portuguese reaction-test wording; the page's live game terms remain mouse/projectile-specific.
- Additional Portuguese intent: [Jogo de Reflexo by fShark](https://fshark.itch.io/jogo-de-reflexo) explicitly uses `teste seu reflexo com o mouse`, and [ClickReflex Portuguese](https://clickreflex.com/pt) uses `teste de reflexo` and mouse-polling terminology.
- Spanish native context: [a Spanish browser reflex-game discussion](https://www.reddit.com/r/DesarrolloWeb/comments/1w1r65r/he_hecho_un_minijuego_web_para_medir_los_reflejos...) confirms active `minijuego web` / `medir los reflejos` intent.
- Additional Spanish intent: [Ritmo Mortal](https://tamacdev.itch.io/ritmo-mortal-tcj) uses `reflejos rápidos`, `esquivar obstáculos`, score, and combo language for a native game audience.
- Additional French intent: [Skill Gap's Réaction de la souris](https://skillgap.pro/fr/blogs/missions/reactivite-de-la-souris) describes mouse reaction, hand-eye coordination, and avoiding projectiles to survive.

## Evidence limits and deployment guardrails

- Google Trends Explore returned no usable query data in this environment, so no trend index or volume number is asserted.
- The repository `.env` does not expose a usable Bing Webmaster API credential, and no GSC dataset was available. No Bing volume/KD figures were invented.
- No Bing API, IndexNow, or indexing submission was called. `ENABLE_INDEXNOW` remains forbidden until deployment.
- The page keeps its full localized guide, FAQ depth, drill rules, scientific explanations, benchmark/protocol content, canonical, hreflang, and structured data. Metadata, visible drill labels, schema naming, locale URLs, and freshness fields were aligned with the localized intent above.
