# Rhythm Anomaly — native SEO/AEO/GEO research

Date: 2026-09-20  
Route: `/drills/visual/visual-recognition/rhythm-anomaly`  
Markets: `ja-JP`, `ko-KR`, `de-DE`, `pt-BR`, `es-ES`, `fr-FR`

## Research boundary

This drill asks the user to find one cell whose pulse is faster or out of phase in a 6×6 visual grid. The search concept is therefore temporal visual discrimination and flicker/pulse perception, not generic music-rhythm training and not a clinical eye examination.

Live web research was performed separately for each locale. Exact Google monthly volume, Google Trends query-level numbers, GSC data, and competitor backlink authority are not available in this workspace. Bing exact-match data is recorded as Bing evidence only and is not represented as Google volume or proof of low competition.

## Native market findings

### Japan — `ja-JP`

- Native terms found in Japanese results: `フリッカーテスト`, `ちらつき検査`, `フリッカー値`, `点滅刺激`, `時間分解能`, and `視覚認知トレーニング`.
- Kotobank defines `フリッカーテスト` as distinguishing intermittent light until it appears continuous and also uses `ちらつき検査`: [Kotobank](https://kotobank.jp/word/%E3%81%B5%E3%82%8A%E3%81%A4%E3%81%8B%E3%83%BC%E3%81%A6%E3%81%99%E3%81%A8-3217887).
- Japanese research uses multiple blinking visual stimuli and SSVEP terminology: [CiNii Research](https://cir.nii.ac.jp/crid/1390009224830878848).
- Bing `フリッカーテスト` returned exact 0 / broad 0 and no related keywords; `点滅 視覚 テスト` also returned exact 0 / broad 0. This is insufficient to call the market zero-demand.
- Primary page intent: `フリッカーテスト` + `視覚の時間分解能`; supporting terms describe native flicker discrimination and phase detection.

### Korea — `ko-KR`

- Native terms tested: `시각 리듬 검사`, `깜빡임 검사`, `플리커 검사`, `시각 시간 분해능`, `시각적 시간 판별`, `위상차 감지`, and `시지각 훈련`.
- Korean search research was heavily noisy for the broad `플리커 검사` seed; Bing related output was dominated by unrelated portal, spelling-check, and image-search queries, with `flicker` appearing only as a generic English token. The page therefore avoids a product-name-first title and uses the Korean visual-perception terms.
- Korean visual-perception training literature supports `시지각`, visual discrimination, and attention-training vocabulary: [KCI visual-perception training study](https://journal.kci.go.kr/jsped/archive/articlePdf?artiId=ART001755016).
- Bing `시각 리듬 검사` and `깜빡임 검사` returned exact 0 / broad 0. This is recorded as weak Bing evidence, not as a Google-demand claim.
- Primary page intent: `시각 리듬 검사`; secondary cluster: `깜빡임 구별`, `시각 시간 분해능`, and `위상차 감지`.

### Germany — `de-DE`

- Native terms found: `Flimmerverschmelzung`, `Flimmerverschmelzungstest`, `Flimmerfusion`, `zeitliche visuelle Auflösung`, `Flimmerfrequenz`, and `zeitliche Diskrimination`.
- German technical material defines `Flimmerverschmelzungsfrequenz` as the point where periodic light changes become a steady visual impression: [LICHT2021 proceedings](https://www.litg.de/media/27622.LICHT2021_Tagungsband.pdf).
- A localized interactive page uses `Flimmerverschmelzungstest` and clearly explains screen-refresh and fatigue limits: [OpticQuiz German flicker test](https://opticquiz.com/de/flicker/).
- Bing `Flimmerverschmelzung` and `visueller Rhythmus Test` returned exact 0 / broad 0; the result is not treated as proof of zero demand.
- Primary page intent: `Flimmerfusion` + `visuelle Zeitauflösung`; supporting terms target temporal discrimination and phase-shift perception.

### Brazil — `pt-BR`

- Native terms found: `discriminação temporal visual`, `teste de ritmo visual`, `resolução temporal visual`, `frequência crítica de fusão`, `teste de cintilação visual`, and `célula fora de fase`.
- Brazilian research explicitly uses `resolução temporal visual` and critical flicker fusion (`CFF`) in a visual-attention context: [USP repository record](https://repositorio.usp.br/item/002844160).
- Local rhythm-test intent uses `teste de ritmo` and evaluates visualized timing intervals, which supports the Portuguese rhythm phrasing without translating the English product name: [HumanBenchLab PT-BR rhythm test](https://humanbenchlab.com/pt-br/t/rhythm).
- Bing `teste de ritmo visual` and `discriminação temporal visual` returned exact 0 / broad 0. Broad `cintilação` is ambiguous in Portuguese and is not used alone as the primary keyword.
- Primary page intent: `discriminação temporal visual`; supporting cluster: `ritmo visual`, `resolução temporal visual`, and `célula fora de fase`.

### Spain — `es-ES`

- Native terms found: `discriminación temporal visual`, `test de ritmo visual`, `fusión de parpadeo`, `resolución temporal visual`, `frecuencia crítica de fusión`, and `celda desfasada`.
- The localized flicker-fusion test uses `fusión de parpadeo` and explains that it reflects how the visual system handles change over time: [OpticQuiz Spanish flicker test](https://opticquiz.com/es/flicker/).
- Spanish visual timing intent also appears in rhythm-test listings that describe a pulsating visual circle and millisecond timing error: [Spanish App Store result](https://apps.apple.com/es/app/rhythm-sense-test/id6761253719).
- Bing `fusión de parpadeo` returned one related result about screen-flicker troubleshooting with 2,219 impressions; `test de ritmo visual` returned exact 0 / broad 0. The related result is adjacent intent, not proof of low competition.
- Primary page intent: `discriminación temporal visual` + `ritmo visual`; supporting cluster targets flicker fusion and phase-offset detection.

### France — `fr-FR`

- Native terms found: `discrimination temporelle visuelle`, `test de rythme visuel`, `scintillement visuel`, `résolution temporelle visuelle`, `fréquence critique de fusion`, and `cellule en déphasage`.
- French display-testing results use `test de scintillement` and explain PWM flicker, refresh behavior, and visual discomfort: [Xbitlabs French flicker test](https://www.xbitlabs.com/fr/pwm-flicker-test/).
- French research terminology uses `discrimination temporelle` and visual temporal-resolution tasks: [Université de Toulouse material](https://medecine.univ-tlse3.fr/medias/fichier/bringer-amandine_1613030772467-pdf?ID_FICHE=1008078&INLINE=FALSE).
- Bing `discrimination temporelle visuelle` returned no related keywords and exact 0 / broad 0 for the tested seed `scintillement visuel`. This is weak Bing evidence only.
- Primary page intent: `discrimination temporelle visuelle`; supporting cluster targets `scintillement`, `résolution temporelle`, and visual phase shifts.

## AEO/GEO implementation decisions

- The title and first metadata phrase lead with native temporal-vision intent instead of the English `Rhythm Anomaly` product label.
- The description states the actual interaction—find the out-of-phase cell in a 36-cell pulsating grid—and explicitly says it is not a medical examination.
- Breadcrumb, SoftwareApplication, WebApplication, VideoGame, HowTo, genre, visible drill title, and subtitle use each locale's native cluster.
- Existing scientific guide depth, benchmarks, four-step protocol, and ten distinct FAQs are retained; scientific names and standard abbreviations such as CFF remain only where they are meaningful technical terminology.
- No exact Google-volume, Google-Trends, GSC, or ranking guarantee is claimed. Bing related/volume output is stored as market evidence, including noise and zero-result limitations.
- No IndexNow or Bing URL submission is run before deployment.
