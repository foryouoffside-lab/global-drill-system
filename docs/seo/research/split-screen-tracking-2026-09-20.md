# Split-Screen Tracking — native SEO/AEO/GEO research

Date: 2026-09-20

## Intent and scope

This drill presents two independent moving targets in separate screen regions. The search intent is visual divided attention, dual-target tracking, peripheral monitoring, and screen-based attention practice. It is a browser practice/measurement task, not a diagnosis or treatment; copy uses observable measures such as target loss, left/right error balance, anchor stability, and response time.

Each locale was researched independently. No English page was translated into a target language.

## Native keyword clusters

### Japan (ja-JP)

Selected phrases: `画面分割 アイトラッキング`, `分割注意力 トレーニング`, `二重注意 視覚追従`, `マルチターゲット 視線分離`, `画面分割 動体視力 テスト`, `周辺視野 動体視力`, `FPS ミニマップ 視線移動 練習`.

Japanese web research uses `分割的注意力`, `視覚的注意`, `動体視力`, and `画面上の動きを追う` for this intent. Lumosity Japan describes divided-attention practice through tracking screen movement and locating important details, while the current drill makes the two-target screen behavior explicit: [Lumosity Japan attention games](https://www.lumosity.com/ja/brain-games/attention-games/).

### Korea (ko-KR)

Selected phrases: `화면 분할 시각 추적`, `분할 주의력 안구 훈련`, `다중 목표 시선 분리`, `주변시 동체시력 훈련`, `FPS 시선 분산 연습`, `다중 표적 추적 검사`, `화면 분할 동체시력`.

The narrow Korean phrases returned no measurable Bing count, so the page keeps the exact divided-attention intent while pairing it with native high-intent terms around `동체시력`, `다중 표적`, `시선 분리`, and FPS screen monitoring. English “split-screen” wording is not used as the Korean page’s primary label.

Selected phrases: `geteilte Aufmerksamkeit Blickverfolgung`, `bilaterales Blickfolgetraining`, `duale Zielverfolgung Auge`, `visuelle Aufmerksamkeit teilen`, `peripheres Blickfeld Übung`, `mehrere Ziele verfolgen`, `Blickverfolgung zwei Ziele`.

German sources consistently use `geteilte Aufmerksamkeit`, `visuelles Scanning`, and simultaneous response to multiple visual channels: [RehaCom attention modules](https://www.rehacom.de/therapiemodule/aufmerksamkeit), [Freie Universität Berlin attention-training overview](https://www.ewi-psy.fu-berlin.de/psychologie/arbeitsbereiche/allg_neuro/studium/bs_aufmerksamkeit.pdf), and [RehaCom screenings](https://www.rehacom.de/screenings). Bing related results for the narrow phrase were noisy, so unrelated “Danke für Ihre Aufmerksamkeit” terms were excluded.

### Brazil / Portuguese (pt-BR)

Selected phrases: `treino de atenção dividida tela dividida`, `rastreamento visual em tela dividida`, `exercício ocular de atenção bilateral`, `visão periférica simultânea`, `rastreamento de múltiplos alvos`, `evitar visão em túnel exercício`, `treino de visão periférica para jogos`.

Bing returned an adjacent relevant cluster for `atividade de atenção e concentração`, including `atividades de atenção` (71) and `atividade de coordenação motora` (177), but generic health and school terms dominated. Those broad phrases are used only with explicit visual-target context. A native Portuguese visual-training source describes following targets on screen and divided attention: [Neuroforma Brasil — Olho Vivo](https://neuroforma.com.br/novo/why-brainhq/about-the-exercises/olho-vivo).

### Spain / Spanish (es-ES)

Selected phrases: `entrenamiento de atención dividida pantalla dividida`, `seguimiento visual en pantalla dividida`, `ejercicio ocular de atención bilateral`, `visión periférica simultánea`, `seguimiento de múltiples objetivos`, `evitar visión de túnel ejercicio`, `rastreo con pantalla dividida`.

### France (fr-FR)

Selected phrases: `entraînement attention divisée écran partagé`, `poursuite visuelle sur écran scindé`, `exercice oculaire attention bilatérale`, `vision périphérique simultanée`, `poursuite de cibles multiples`, `exercice contre la vision tunnel`, `poursuite visuelle écran partagé`.

## Scientific and AEO framing

The guide keeps the existing peer-reviewed references for multiple-object tracking, divided attention, visual attention, and display timing. The page answers practical questions directly: whether two targets can be tracked, why a central anchor is used, what left/right asymmetry means, how screen refresh affects measurement, and how to progress difficulty. It does not promise improved eyesight, clinical recovery, or guaranteed game performance.

## Measurement limitations

The local Bing utility provides directional market counts and related-query suggestions, not Google Keyword Planner, Google Trends, Search Console, or a true competition metric. Several exact phrases returned zero because they are narrow; zero is not proof of zero Google demand. No No. 1 ranking can be guaranteed.

No Bing submission, IndexNow request, or deployment was performed. `npm run build` was intentionally not run because this project’s postbuild can submit IndexNow URLs.
