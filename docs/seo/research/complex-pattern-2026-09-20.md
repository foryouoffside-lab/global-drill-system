## Scope and guardrails

This pass covers one drill only. Each localized page keeps native search wording and gamer/cognitive-test vocabulary; no English page was translated into another language. The existing full guide, scientific working-memory introduction, benchmark table, tracing protocols, and ten-question FAQ set were preserved.

Complex Pattern is not a generic card-matching game. Its interaction is: observe a briefly flashing geometric path, hold the spatial pattern, then drag the mouse through the waypoints in order. The search strategy therefore combines visual-memory and spatial-memory demand with sequence recall, browser memory-game, and path-tracing intent.

Exact country search volume, Google Trends indices, Google Search Console queries, and reliable difficulty scores were not available in this workspace. Autocomplete/SERP wording is evidence of query shape, not a monthly-volume number. No unsupported “low competition” or #1 probability claim is made, and no Bing/IndexNow submission was performed.

## Live SERP evidence

The live results consistently present this category as a short browser test or memory game: briefly show a pattern or sequence, hide it, and ask the user to reproduce it. Strong result pages also explain that a browser score is recreational and should not be presented as a clinical diagnosis.

- English: [ReflexBench Pattern Memory](https://reflexbench.com/assessments/pattern-memory/) describes visual-spatial working-memory encoding and recall; [Memory-Game.net Spatial Memory](https://memory-game.net/spatial-memory-game) uses browser visual-spatial route recall; [Burnjet Neural Maze](https://burnjet.com/games/neural-maze) combines illuminated-path memorization with sequential motor reproduction.
- Japan: [webtools-lab Japanese aim/memory tools](https://webtools-lab.com/tools/aim-trainer/) demonstrates Japanese browser-test wording and separates memory/visual tasks from reflex tests; [Shooting Aim Trainer Japanese](https://shootingaimtrainer.com/ja/) reinforces browser, performance-report, and mouse-practice language. Shape-memory and spatial-awareness terms were retained from Japanese native SERP suggestions.
- Korea: native results were noisy, but Korean cognitive-test terminology repeatedly centered on `도형 순서 기억하기`, `순서 기억`, `공간 기억력`, and `패턴 기억력`; unrelated entertainment and gambling results were excluded.
- Germany: [Benton-Test German reference](https://de.wikipedia.org/wiki/Benton-Test) confirms the native visual-spatial memory vocabulary around remembering and reproducing figures; German SERP language also uses `Muster merken`, `visuelles Gedächtnis`, and `räumliches Vorstellungsvermögen`.
- Brazil/Portuguese: [Climodo Corsi test PT](https://www.climodo.com/pt/corsi-block-tapping-test) uses repeatable browser sequence recall and explicitly frames pattern grouping as useful; [GameTan sequence memory PT](https://gametan.ai/pt/tests/sequence-memory) uses `memória de sequência` and the visuospatial working-memory concept; [Memo visual-memory PT](https://www.memo-app.com/pt/tools/visual-memory-test) uses visual-pattern recall language.
- Spain: [NEURA Corsi test ES](https://neurabrain.app/es/test/corsi-block) uses `test de los cubos de Corsi`, `span visual`, and reproducing spatial positions in a browser; [AimBst memory test ES](https://aimbst.com/es/test-de-memoria/) distinguishes a recreational browser self-test from a formal assessment; [gottrix visual-memory test](https://gottrix.app/es/test-de-memoria-visual) uses short-term spatial-memory and grid-reproduction language.
- France: [OnlineMemoryTest FR](https://onlinememorytest.com/fr) uses free browser visual-memory testing, pattern recognition, short-term recall, and illuminated-grid reproduction. These signals support `mémoire visuelle`, `mémoire spatiale`, and `test mémoire` rather than a literal translation of the English title.

## AEO and GEO implementation record

- Titles lead with the native visual-memory or pattern-memory query and include the SkillDrills brand hook within the title-length limit.
- Descriptions answer the task directly: memorize the flashing path, redraw it, and train spatial/working memory and coordination.
- The existing localized FAQ schema contains ten genuine questions covering measurement, controls, scientific models, difficulty, accuracy, FPS transfer, motor chunking, sensitivity, elite scoring, and access.
- Breadcrumb, SoftwareApplication, WebApplication, VideoGame, FAQPage, and HowTo schemas remain present. Locale tags and `dateModified: 2026-09-20` were aligned across the seven pages.

- The English route received one sitemap freshness override; locale alternates continue through the existing `getAlternateLanguages` matrix.

4. Backlink/domain authority was not measured, so no authority advantage is claimed.
