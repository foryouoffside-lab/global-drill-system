# Path Tracing / Corsi Block Research — 2026-09-20

## Scope

One drill only: `memory/spatial-memory/path-tracing`, optimized independently for the six supported localized routes: `de-DE`, `es-ES`, `fr-FR`, `ja-JP`, `ko-KR`, and `pt-BR`. This is native search research, not a translation of the English page.

## Evidence and limits

- Bing keyword endpoint was queried for the local Corsi/sequence-memory head terms in each market. The public response returned zero exact and broad volume for the sampled niche phrases; this is recorded as sparse-tool evidence, not as proof of zero Google demand.
- Live localized SERP research found direct task intent in German, Spanish, French, Japanese, Korean, and Portuguese pages. The strongest recurring intent is a free browser test that shows blocks in sequence and asks the user to reproduce the same order.
- Google Trends and Search Console data are not authenticated in this workspace. No IndexNow or Bing submission was made, and no URL was sent to a search engine.
