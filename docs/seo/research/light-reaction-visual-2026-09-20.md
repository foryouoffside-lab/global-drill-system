# Light Reaction — visual drill native SEO/AEO/GEO research

Research date: 2026-09-20  
Route: `/drills/visual/reaction-speed/light-reaction`  
Markets: Japan (`ja-JP`), South Korea (`ko-KR`), Germany (`de-DE`), Brazil (`pt-BR`), Spain (`es-ES`), France (`fr-FR`)

## Decision gate

Keep the six existing localized pages. The live SERPs show that users generally search for a visual reaction-time or reflex test, while the light/strobe stimulus is the drill's differentiator. The implementation therefore leads with the native reaction-time/reflex term and explains the light stimulus in the description, visible drill title, FAQ, and HowTo context.

This is a browser performance drill, not a medical reflex examination. Online scores include display, browser, input, attention, and device latency. No #1 ranking is guaranteed; post-deployment Search Console and Bing performance must validate the market choices.

## Implementation audit

1. Each locale was researched independently; no English page was machine-translated.
2. Metadata titles and descriptions front-load the measured local reaction/reflex phrase and keep the SkillDrills suffix compact.
3. Keyword arrays combine measured Bing anchors with native SERP-supported long-tail terms; zero/noisy endpoint results are not presented as demand.
4. Visible drill titles and start-card subtitles are short and localized for the existing one-line UI treatment.
5. Guide headings, benchmark titles, and training headings now answer local search intent while preserving all existing scientific introductions, benchmark rows, calibration details, citations, and 10 FAQ entries.
6. The light/strobe stimulus remains explicit so the page does not compete as a generic reaction test only.
7. Sitemap freshness is overridden only for this route and its localized pages.
8. No IndexNow or Bing submission endpoint was called.
