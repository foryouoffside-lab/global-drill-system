# Spatial Shift Pursuit — native SEO/AEO/GEO research

Date: 2026-09-20

## Intent and scope

This page serves people who want to keep following a visible target while the screen, camera, or visual reference frame shifts. It is a browser practice and measurement drill, not a medical test or treatment. The copy therefore describes observable practice measures—reacquisition time, tracking accuracy, and positional error—without promising clinical, esports, or ranking outcomes.

Research was performed separately for Japanese, Korean, German, Brazilian Portuguese, Spanish, and French. The page copy was authored for each locale's search language; it was not translated from the English page.

## Native keyword clusters selected

### Japan (ja-JP)

Primary intent: `視界ブレ エイム 練習`, `空間シフト 追従`, `カメラ移動 エイム 安定化`.

Supporting demand terms: `動体視力トレーニング`, `動体視力テスト`, `深視力トレーニング`, `ビジョントレーニング`, `空間認知`, `視線追従`, `視野ズレ 練習`.

Bing's related report for `動体視力 トレーニング` returned `動体視力トレーニング` (257), `動体視力テスト` (232), `深視力 トレーニング` (198), `ビジョン トレーニング` (93), and `空間認知`-adjacent training language. The exact drill-specific phrase returned no Bing volume, so it remains a focused long tail rather than a claimed high-volume term.

### Korea (ko-KR)

Primary intent: `화면 흔들림 에임 연습`, `공간 시프트 추적 훈련`, `시야 좌표계 적응`.

Supporting demand terms: `에임연습` (2,517 related), `에임 연습 사이트` (763), `발로란트 에임 연습 사이트` (505), `에임 연습` (211), `에임연습 사이트` (206), `발로란트 에임 연습` (135).

The broad demand terms are used only where the page actually describes browser target-following practice; the drill-specific terms retain the spatial-shift intent.

### Germany (de-DE)

Primary intent: `räumliche Aufmerksamkeit Training`, `Blickfeld Verschiebung Übung`, `verschobenes Sichtfeld Ziel verfolgen`.

Supporting terms: `räumliche Blickverfolgung`, `Sichtfeldwechsel Training`, `Ziel wiedererfassen Blickübung`, `visuelle Reakquisition`, `bewegtes Sichtfeld Übung`.

Bing returned no related phrases for the highly specific German strings. Native sources use the established vocabulary `räumliche Aufmerksamkeit`, `Blickverfolgung`, and `visuell-räumliche Aufmerksamkeit`, so those terms are preferred over an English “Spatial Shift” label.

### Brazil / Portuguese (pt-BR)

Primary intent: `mudança espacial rastreamento visual`, `remapeamento visual treino`, `tela tremendo mira treino`.

Supporting terms: `seguir alvo com campo visual móvel`, `atenção espacial exercício`, `reacquisição visual treino`, `mudança de referencial visual`, `rastreamento sob movimento de tela`, `coordenação olho alvo`, `erro de posição visual`.

Bing's related report for `treino de rastreamento visual` returned the relevant adjacent query `treino de mira` (263) and `treino de mira valorant` (118), while generic fitness terms dominated. The copy therefore keeps the visual-tracking intent explicit and does not chase unrelated high-volume fitness phrases.

### Spain / Spanish (es-ES)

Primary intent: `cambio espacial seguimiento visual`, `remapeo visual ejercicio`, `pantalla temblando puntería`.

Supporting terms: `seguir objetivo con campo visual móvil`, `atención espacial entrenamiento`, `readquisición visual ejercicio`, `cambio de marco visual`, `seguimiento con pantalla en movimiento`, `coordinación ojo objetivo`, `error de posición visual`.

Bing's broad `seguimiento visual` result set was dominated by parcel tracking, not visual training. That ambiguity is excluded from titles and headings; the page uses `seguimiento de objetivos`, `atención espacial`, and `remapeo visual` to make the intent unambiguous.

### France (fr-FR)

Primary intent: `saut spatial poursuite visuelle`, `remappage visuel exercice`, `écran qui tremble entraînement visuel`.

Supporting terms: `suivre une cible dans un champ mobile`, `attention spatiale exercice`, `réacquisition visuelle entraînement`, `changement de repère visuel`, `poursuite sous mouvement d'écran`, `coordination œil cible`, `écart de position visuelle`.

Bing's related report for `poursuite visuelle` returned the relevant `recherche visuelle` cluster, but that term is ambiguous with image search. The page keeps `poursuite visuelle` paired with `cible`, `champ visuel`, and `réacquisition`.

## Measurement limitations

The project’s Bing utility supplies directional market counts and related-query signals, not Google Keyword Planner, Google Trends, Search Console, or a true competition score. Several drill-specific phrases returned zero in Bing because they are narrow; zero is not proof of zero Google demand. “High demand / low competition” is therefore treated as a hypothesis to validate after deployment, not a guaranteed fact. No page can be guaranteed to rank number one.

No Bing submission, IndexNow request, or deployment was performed. `npm run build` was intentionally not run because this project’s postbuild can submit IndexNow URLs.
