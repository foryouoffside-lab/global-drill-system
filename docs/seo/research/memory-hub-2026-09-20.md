# Memory category hub research — 2026-09-20

Scope: the memory drill-selection hub and its six country-language variants. This note does not claim a guaranteed ranking position or invent monthly search volume.

## Native query direction

| Market | Primary native cluster | Supporting intent | Implementation direction |
| --- | --- | --- | --- |
| Korea (`ko-KR`) | 기억력 테스트, 기억력 훈련 | 작업기억, 숫자 기억, 시공간 기억 | Lead with test/training language; keep 작업기억 and visual-spatial practice as supporting entities. |
| Japan (`ja-JP`) | 記憶力 テスト, 記憶力 トレーニング | ワーキングメモリ, 数字記憶, 空間記憶 | Use the spaced search phrasing common in Japanese titles and pair it with concrete task names. |
| Germany (`de-DE`) | Gedächtnistest, Gedächtnistraining | Arbeitsgedächtnis, Zahlenspanne, räumliches Gedächtnis | Put the test/training compound first and explain the three task families in native German. |
| Brazil (`pt-BR`) | teste de memória, treino de memória | memória de trabalho, memória espacial, span de dígitos | Use Brazilian “teste/treino” intent and expose number, visual, and spatial exercises. |
| Spain / LATAM (`es-ES`) | test de memoria, entrenamiento de memoria | memoria de trabajo, memoria espacial, span de dígitos | Keep “test” and “entrenamiento” distinct and use task-specific long-tail terms. |
| France (`fr-FR`) | test de mémoire, entraînement de la mémoire | mémoire de travail, empan de chiffres, mémoire spatiale | Lead with the French test/training nouns; avoid English “memory game” wording. |

## Live SERP evidence

The live search pass found interactive or practice-oriented results in the native markets. The wording below was used as intent evidence, not as a volume number:

- Japan: [Japanese digit-memory task PDF](https://ruggero.sci.yokohama-cu.ac.jp/data/Ito_Degree.pdf) uses `記憶力に関するテスト` and a timed digit sequence task; [Japanese working-memory reference](https://books.google.co.jp/books?hl=ja&id=TNGOoAEACAAJ&lr=&num=20) uses `ワーキングメモリ`.
- Korea: [Korean visual-spatial memory-training research PDF](https://www.accesson.kr/healthpsy/assets/pdf/19167/journal-20-4-855.pdf) explicitly uses `기억력 훈련`, `시공간기억`, and practice/start actions.
- Germany: [Brain-fit](https://www.brain-fit.com/training/gedaechtnistraining.html) presents `Gedächtnistraining online`; [NerdSip](https://nerdsip.com/de/tests/gedaechtnistest/) pairs `Gedächtnistest` with an adaptive `Zahlenspanne` and states that an online test is not diagnostic.
- Brazil: [Tua Saúde](https://www.tuasaude.com/teste/memoria/) uses `Teste de memória visual (online)`; [Neurotasks](https://www.neurotasks.com.br/) exposes `Memória de Trabalho`; [Train the Brain](https://trainthebrain.app/pt/jogos-de-memoria) groups `Memória de Sequência`, `Memória Visual`, and `Memória de Números`.
- Spain / LATAM: [Tua Saúde España](https://www.tuasaude.com/es/test-online-memoria/) uses `Test de memoria online`; [Online Memory Test ES](https://onlinememorytest.com/es) describes visual and short-term memory; [Fijate](https://fijate.com/tools/test-memoria/) names the Corsi visuospatial working-memory task.
- France: [HAPPYneuron](https://www.happyneuron.fr/test-memoire.html) uses `test mémoire`, `travail de la mémoire`, and online exercises; [ConnectFly](https://connect-fly.fr/memoire-de-travail-alat.html) presents an interactive `test de mémoire de travail` and native chunking language.

## Evidence limits and safeguards

Search results establish local phrasing, task vocabulary, and tool intent. They do not establish Google monthly volume, Google Trends index, or a low-competition guarantee. No numeric volume has been fabricated here. GSC, Google Trends, and authenticated country-specific Bing Webmaster data still require the site owner’s connected accounts and should be checked before deployment decisions.

The implementation uses native copy authored for each locale, not a word-for-word translation of the English page. The page keeps claims bounded: browser scores are practice measurements, not IQ or medical tests. IndexNow/Bing submission was not performed.
