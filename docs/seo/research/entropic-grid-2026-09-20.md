# Entropic Grid — native SEO/AEO/GEO research

Research date: 2026-09-20

Localized routes: `/ja/`, `/ko/`, `/de/`, `/pt/`, `/es/`, `/fr/`

## Research boundary

This drill is a browser visual-search task: find a short target code in a 10×10 grid while cells change under visual noise. The search intent is human visual search, selective attention, visual scanning, concentration, and interference filtering. It is not image search, reverse-image search, an eye-health diagnosis, or an AI computer-vision product.

The six existing localized guides, scientific introductions, benchmark tables, protocols, and ten-question FAQ sets will be preserved. Search-facing copy is being rewritten from native local terminology; the English page is not being translated into other languages.

Exact Google monthly volume, Google Trends query-level numbers, GSC query data, and competitor backlink authority are not available in this workspace. Bing related-query output is recorded as Bing evidence only; it is not presented as Google volume or proof of low competition. The localized web SERPs provide intent and terminology evidence.

## AEO/GEO implementation decisions

- Each title front-loads the locally observed human visual-search entity and keeps the subtitle short.
- Descriptions state the grid action and selective-attention benefit without diagnosing eyesight or promising medical improvement.
- Existing localized scientific depth, benchmark tables, procedures, and ten distinct FAQs remain intact.
- Structured-data names, breadcrumbs, drill labels, and the interactive H1/subtitle are aligned to the same localized intent.
- Localized canonical and alternate-language metadata remain self-referencing and reciprocal.
- The sitemap gets a page-specific last-modified override only after this drill changes.
- No IndexNow/Bing submission will be run before deployment.
